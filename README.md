# QA Portfolio | Pedro Macedo

Portfólio de projetos de prática em qualidade de software: testes manuais, documentação de testes e automação.

> Todos os projetos aqui são de estudo e prática. Nenhum deles representa experiência profissional em QA.

## 🧰 Ferramentas

- **Testes manuais e documentação:** Markdown, Gherkin, DevTools
- **Automação:** Cypress (JavaScript)
- **API:** Postman
- **Dados:** SQL Server
- **Versionamento:** Git e GitHub

## 📁 Estrutura

```
qa-portfolio/
├── README.md
├── templates/            # modelos de bug report, caso de teste e plano de testes
│   ├── bug-report.md
│   ├── test-case.md
│   └── test-plan.md
└── docs/                 # estudos (ISTQB/CTFL, glossário)
```

Projetos completos ficam em repositórios próprios:

| Projeto | Descrição |
|---|---|
| [fork-community-qa](https://github.com/pepemacedo/fork-community-qa) | Estudo de Cypress: testes automatizados do fluxo de acesso da central da comunidade Fork |

## 📏 Convenções

- Nomes de pastas e arquivos em `kebab-case`
- IDs: `TC-001` (caso de teste), `BUG-001` (bug)
- Todo bug com passos, resultado esperado, resultado obtido e evidência
