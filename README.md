# QA Portfolio | Pedro Macedo

Portfólio de projetos de prática em qualidade de software: testes automatizados, cenários em BDD e documentação de testes.

> Todos os projetos aqui são de estudo e prática. Nenhum deles representa experiência profissional em QA.

**English summary:** Junior QA in training, coming from ERP support and implementation work with international clients. This repository gathers my hands-on practice: Cypress end-to-end tests, BDD scenarios written in Gherkin and testing templates. Documentation is in Portuguese; I'm happy to walk through any project in English.
